About the Project

Problem Statement

Students often find it difficult to understand how their academic performance, technical skills and professional experience may influence their placement opportunities.

Proposed Solution

PlacementAI uses machine learning algorithms to estimate placement probability based on student academic, technical and professional characteristics.

Machine Learning Algorithms

  • Logistic Regression
  • Decision Tree
  • Random Forest

Dataset

The project uses a dataset containing approximately 100,000 student records.

Technology Stack

Python Flask Pandas Scikit-learn SQLite HTML CSS JavaScript
